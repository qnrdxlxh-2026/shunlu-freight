# 顺路货运撮合平台 - 开发完成

## 项目概述
- **名称**: 顺路货运撮合平台
- **定位**: 甘孜州、阿坝州起步，信息撮合模式
- **用户**: 商家、货车司机、私家车主、运营管理

## 技术实现
- **后端**: 纯Node.js内置模块（无外部依赖）
- **数据库**: JSON文件模拟（可无缝切换MySQL）
- **前端**: 单页HTML管理后台
- **端口**: 3458

## 合规约束 ✅

### 私家车约束（已测试通过）
- 单票重量 ≤ 20kg ✅
- 单票货值 ≤ 2000元 ✅
- 单日接单 ≤ 2单 ✅
- 佣金率 12% ✅

### 货车约束
- 佣金率 6% ✅
- 实名认证要求 ✅
